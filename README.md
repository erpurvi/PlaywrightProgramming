# Playwright Programming

Learning repository for **JavaScript, TypeScript, and Playwright** — SDET automation practice.

Code and notes are added chapter by chapter as I progress through the course. JavaScript fundamentals come first, then TypeScript, then Playwright for end-to-end automation.

## What's covered

- **JavaScript Fundamentals** — variables, operators, control flow, loops, arrays, functions, strings, objects, callbacks, promises, async/await
- **Object-Oriented Programming** — classes, encapsulation, inheritance, polymorphism
- **TypeScript** — types, interfaces, enums, generics, access modifiers, decorators
- **Playwright** — setup, config, end-to-end tests
